Watermelon Bed Fertilizer Calculator

Pre-plant fertilizer planning, blend calculations and spreader calibration

Prototype calculation model. This version reproduces the formulas found in the supplied Excel workbook. It has not yet been agronomically validated or connected to an Extension submission database. Review the recommendations and unit conversions before using it to make fertilizer decisions.

1. Field information

Enter the field dimensions. Row acres are calculated from planted row length, number of rows and row spacing.

7. Optional: share results with UF/IFAS Extension

Using the calculator does not submit information. If you choose to share, the application will prepare a data file for submission. This prototype does not transmit or store information at UF/IFAS; a secure Extension connection must be configured before public release.
